What is a Text Formatter?

A text formatter automates structural edits like adding bullet prefixes, custom line suffixes, indenting code or prose, and standardizing sentence spacing across multiple paragraphs.

Useful Features

- Line Prefixes & Suffixes: Turn lines into bulleted lists or wrap items in quotes/commas.
- Indentation: Add 2 spaces, 4 spaces, or tabs to each line.
- Sentence Spacing: Standardize single vs double spacing after sentence terminators.

Frequently Asked Questions

Can I convert a plain list into a bullet list?

Yes. Click "Add Bullet Points" or type a custom character in the Line Prefix input box.

Does text formatting alter original words?

No. Text Formatter only adjusts line prefixes, suffixes, indentations, and spacing rules.
