What is a Text Case Converter?

A text case converter is an online tool that changes the capitalization of text without requiring you to edit every word manually.

How to use this tool?

Paste or type your text into the editor, then select the case you want. You can copy the result, download it, or clear the editor and start again.

Available text cases

Use uppercase for all capital letters, lowercase for small letters, title case for headings, sentence case for normal sentences, and capitalized case to capitalize each word.
